#  مشروع تحويل الكلام إلى نص


##  المميزات الأساسية  
 **تحليل الصوت بدقة عالية** باستخدام مكتبة `speech_recognition`.  
 **دعم اللغتين العربية والإنجليزية**.  
 **واجهة ويب تفاعلية** لتحويل الصوت إلى نص.  
 **تصميم جذاب وسهل الاستخدام**.  
 **إدارة الأخطاء بذكاء** في حالة انقطاع الإنترنت أو ضعف الصوت.
